# UnbreakableSurfaces

Bridges and unstable platforms never collapse.

**Host should run this.** Falls are blocked on the server.

## What it covers

- Metal bridges (`BridgeTrigger`) — durability stays full, fall RPCs blocked
- Unstable / wooden platforms (`BridgeTriggerType2`) — instability never accumulates

## Config

| Key | Default | Notes |
| --- | --- | --- |
| `Enabled` | true | Master toggle |
| `Bridges` | true | Classic collapsing bridges |
| `BreakableSurfaces` | true | Type-2 unstable surfaces |
